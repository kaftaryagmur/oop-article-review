# Araştırma Notları İndeksi

Önerilen okuma sırası:

1. `../PROJECT_CONTEXT.md` — amaç, kısıtlar ve çalışma durumu.
2. `../assignment-requirements.md` — ödev belgesinden çıkarılan Seçenek B koşulları.
3. `paper-evidence.md` — özgün makaleden çıkarılan doğrulanmış kanıtlar.
4. `verification-log.md` — ön analiz iddialarının doğru, hatalı veya belirsiz olarak ayrılması.
5. `source-analyses/` — dört ham analiz; yalnızca araştırma girdisi olarak kullanılmalıdır.

## Kanıt düzeyleri

- **Doğrulandı:** Özgün makalenin metin, tablo veya şekli açıkça destekliyor.
- **Düzeltildi:** Analizdeki ifade özgün kaynakla çelişiyor veya yanlış payda/etiket kullanıyor.
- **Yorum:** Makul akademik çıkarım; makalenin doğrudan bulgusu değildir.
- **Belirsiz:** Özgün makalenin mevcut kanıtı iddiayı kesinleştirmeye yetmiyor.

Ana makalenin kararlı bağlantıları: [arXiv özet](https://arxiv.org/abs/2004.10777), [arXiv HTML tam metin](https://arxiv.org/html/2004.10777v1), [yayın DOI'si](https://doi.org/10.1016/j.jss.2020.110610).
